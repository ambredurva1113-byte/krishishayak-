# KrishiSahayak — Agricultural Risk Prediction System

Predictive early-warning system for crop distress across Maharashtra districts, using real historical rainfall, temperature, and yield data to classify each district-crop-year as **Low / Medium / High** risk, with a bilingual (English/Marathi) Streamlit dashboard.

## Dataset — real, publicly available (assignment-compliant)
- **Source:** GitHub repository `Runax15/crop-yield-prediction-maharashtra` — `https://github.com/Runax15/crop-yield-prediction-maharashtra` (GitHub is explicitly listed as an acceptable source in your assignment PDF, Section 4)
- **Underlying data:** Maharashtra government agricultural statistics (district-wise crop area, production, yield) merged with rainfall and temperature records
- **Raw file used:** `final_crop.csv` from that repo (included here as `raw_final_crop.csv`)
- **Coverage:** 25 real Maharashtra districts (Mumbai/Bombay excluded — non-agricultural), 14 real crops, 1999–2017
- **Final model-ready rows:** 4,684 (well above the assignment's 500-row minimum)
- **Target variable:** `risk_level` (Low/Medium/High) — engineered from real yield and rainfall data, see methodology below

## Methodology — read this before your viva
**Prediction granularity:** risk is predicted per district-crop-year, not just per district. A district can be low-risk for cotton but high-risk for rice in the same year — this is more realistic and gives farmers usable, crop-specific advice.

**How the risk label is built:** `distress_score = 0.65 × (this year's yield shortfall vs. the district-crop's own prior 3-year average) + 0.35 × (rainfall deviation from district normal)`, then split into tertiles (Low/Medium/High). Every number in this formula is real — nothing fabricated.

**Data leakage — important, be ready to explain this:** An earlier version of this pipeline fed the *same* yield-change numbers used to build the label back in as model predictors, producing an unrealistic ~99% accuracy — the model was just reading its own answer key. This was caught and fixed. The current version strictly separates:
- **Label inputs** (only used to define Low/Medium/High): current year's yield vs. its own prior baseline
- **Predictor inputs** (what the model actually sees): only information available *before* the year's outcome is known — current-year rainfall & temperature, area sown, and the district-crop's own **prior-year** yield statistics (lagged with `.shift(1)`, so the current year never leaks into its own predictors)

This is what makes it a genuine early-warning model rather than a model that "predicts" an outcome using the outcome itself. **Be ready to explain this distinction in your viva — it's exactly the kind of thing that separates a strong submission from an average one.**

## Honest results (real data)
| Model | Accuracy | F1 (macro) | ROC-AUC |
|---|---|---|---|
| Logistic Regression (baseline) | 57.5% | 0.570 | 0.761 |
| **XGBoost (main model)** | **63.9%** | **0.638** | **0.816** |

XGBoost meaningfully outperforms the baseline, which is what you'd expect given non-linear weather-yield relationships. The confusion matrix shows High and Low risk are identified reliably; Medium is the hardest class to separate — which is realistic, since "medium distress" is inherently a fuzzier middle ground than the two extremes.

**Top predictors:** rainfall deviation from normal, absolute rainfall, average temperature, prior 3-year average yield, area sown — all directly interpretable and defensible.

## Known limitation (state this explicitly in your report)
No clean public dataset exists at district level for **market prices** or **farmer debt/loan stress** for this period — this is a genuine data-availability gap, not an oversight. The model therefore captures climate and yield-based distress, not financial distress. Reporting this honestly is stronger academic practice than fabricating a fourth data source.
